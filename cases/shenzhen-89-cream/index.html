业主需求与痛点#

业主是一对 90 后夫妻，房子是首套刚需三房，预算敏感但对颜值要求高。他们希望「回家不用摸开关」，同时要照顾家里的猫。

  • 玄关到客厅动线长，晚上回家一片黑，摸不到开关。
  • 担心小户型做智能会显得杂乱、设备堆得到处都是。
  • 养猫，长期不在家时担心温度和空气。

方案要点#

  1. 无主灯分层照明：客厅用磁吸轨道 + 洗墙灯槽代替主灯，视觉层高提升约 30cm 的观感
  2. 零散设备集中收纳：网关、交换机统一放在玄关柜内的迷你弱电箱，明面上看不到任何设备
  3. 墙面奶油色 + 木格栅点缀：大面积奶油色乳胶漆 + 局部木格栅，避免小户型显得空旷或压抑
  4. 宠物关怀自动化：客厅温湿度传感器 + 空调 / 除湿联动，离家超过 8 小时自动巡检并推送
  5. 只做 4 个核心场景：回家 / 离家 / 观影 / 睡眠，避免自动化过多导致家人困惑

这个案例值得参考的地方#
