适老化的优先级排序：安全（燃气/水浸/跌倒）> 无障碍（起夜灯、语音）> 舒适（温湿度自动调节）。所有设计都要保留物理开关——对老人来说，能被摸到的按键比语音更可靠。

一、老人居所：五个必备#

  1. 起夜路径照明：床下地脚灯 + 卫生间 5% 暖光，亮度不超过 10%，从床边依次点亮。
  2. 安全报警：燃气、水浸、烟感联网，触发时全屋语音播报 + 手机推送，而不只是 App 里一条消息。
  3. 一键呼叫：床头无线按钮，按下后同时通知子女手机与本地语音播报。
  4. 跌倒与久无活动检测：卫生间与卧室用毫米波雷达（不装摄像头），超过设定时长无活动即通知。
  5. 大字号面板与语音：面板字高足够、按键行程明显，语音指令只保留 3–5 条最常用的。

二、无障碍细节#

  • 开关高度：老人常用开关建议 0.9–1.1 米，避免弯腰。
  • 夜间不刺眼：走廊夜灯色温 2200–2700K。
  • 语音语速：调慢语速、减少回复内容，避免长句子。
  • 让老人参与设置：让老人自己决定「哪些灯自动亮」，接受度会显著提高。

三、儿童房设计#

  • 护眼照明：学习桌照度 500lx 以上，色温 4000K 左右，Ra≥90，无频闪。
  • 睡眠场景：入睡渐暗（15 秒），夜间保留 1% 微光，方便查看。
  • 学习场景：一键切换台灯 + 主灯 + 静音模式（关掉吸尘器、洗衣机提示音）。
  • 成长适配：幼儿期用语音睡前故事，学龄期加书桌灯与定时提醒。

四、隐私边界：摄像头不是万能方案#

  • 卧室、卫生间不要装摄像头，用雷达与门磁替代。
  • 客厅摄像头设定「在家自动遮蔽/关闭」。
  • 明确告知家人录制范围与存储位置（本地存储优于云存储）。
  • 儿童看护优先用音频 + 状态提示，而不是全天视频。

适老化项目真正的难点不是技术，而是让老人愿意用。方案越简单、越接近原有习惯，成功率越高。

五、交付时给家人的一页纸#

  1. 三个最常用的手动操作（在哪、按几下）。
  2. 报警发出后第一步做什么（谁的电话、如何解除）。
  3. 断网了怎么办（哪些功能仍可用）。
  4. 联系谁（售后电话 + 微信）。

还有疑问？

老人不愿意用智能设备怎么办？

先从「不用学就会用」的功能开始：自动感应夜灯、燃气报警、自动关灯。这类功能不需要老人做任何操作，接受度最高。

跌倒检测准确吗？

毫米波雷达对「长时间静止 + 姿态异常」的识别已较成熟，但仍有误报。建议作为辅助预警，配合一键呼叫按钮使用，不要作为唯一手段。

儿童房用智能灯会影响视力吗？

关键参数是照度、显色指数、频闪与眩光，而不是「智能」本身。选无可见频闪（无频闪认证）、Ra≥90、可调色温的产品，并按标准布置照度。
