適老化的優先級排序：安全（燃氣/水浸/跌倒）> 無障礙（起夜燈、語音）> 舒適（溫溼度自動調節）。所有設計都要保留物理開關——對老人來說，能被摸到的按鍵比語音更可靠。

一、老人居所：五個必備#

  1. 起夜路徑照明：床下地腳燈 + 衛生間 5% 暖光，亮度不超過 10%，從床邊依次點亮。
  2. 安全報警：燃氣、水浸、煙感聯網，觸發時全屋語音播報 + 手機推送，而不只是 App 裡一條消息。
  3. 一鍵呼叫：床頭無線按鈕，按下後同時通知子女手機與本地語音播報。
  4. 跌倒與久無活動檢測：衛生間與臥室用毫米波雷達（不裝攝影機），超過設定時長無活動即通知。
  5. 大字號面板與語音：面板字高足夠、按鍵行程明顯，語音指令只保留 3–5 條最常用的。

二、無障礙細節#

  • 開關高度：老人常用開關建議 0.9–1.1 米，避免彎腰。
  • 夜間不刺眼：走廊夜燈色溫 2200–2700K。
  • 語音語速：調慢語速、減少回復內容，避免長句子。
  • 讓老人參與設置：讓老人自己決定「哪些燈自動亮」，接受度會顯著提高。

三、兒童房設計#

  • 護眼照明：學習桌照度 500lx 以上，色溫 4000K 左右，Ra≥90，無頻閃。
  • 睡眠場景：入睡漸暗（15 秒），夜間保留 1% 微光，方便查看。
  • 學習場景：一鍵切換檯燈 + 主燈 + 靜音模式（關掉吸塵器、洗衣機提示音）。
  • 成長適配：幼兒期用語音睡前故事，學齡期加書桌燈與定時提醒。

四、隱私邊界：攝影機不是萬能方案#

  • 臥室、衛生間不要裝攝影機，用雷達與門磁替代。
  • 客廳攝影機設定「在家自動遮蔽/關閉」。
  • 明確告知家人錄製範圍與存儲位置（本地存儲優於雲存儲）。
  • 兒童看護優先用音頻 + 狀態提示，而不是全天影片。

適老化專案真正的難點不是技術，而是讓老人願意用。方案越簡單、越接近原有習慣，成功率越高。

  1. 三個最常用的手動操作（在哪、按幾下）。

  3. 斷網了怎麼辦（哪些功能仍可用）。
  4. 聯繫誰（售後電話 + 微信）。

還有疑問？

老人不願意用智慧設備怎麼辦？

先從「不用學就會用」的功能開始：自動感應夜燈、燃氣報警、自動關燈。這類功能不需要老人做任何操作，接受度最高。

跌倒檢測準確嗎？

毫米波雷達對「長時間靜止 + 姿態異常」的識別已較成熟，但仍有誤報。建議作為輔助預警，配合一鍵呼叫按鈕使用，不要作為唯一手段。

兒童房用智慧燈會影響視力嗎？

關鍵參數是照度、顯色指數、頻閃與眩光，而不是「智慧」本身。選無可見頻閃（無頻閃認證）、Ra≥90、可調色溫的產品，並按標準布置照度。
