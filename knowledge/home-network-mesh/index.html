家庭网络的正确形态是：光猫桥接 → 主路由 → 交换机 → 各房间 AP（有线回程）。只要是自有住房、且在水电阶段能布线，就不要用无线回程 Mesh。判断标准也很简单：能用网线连的，绝不用无线连。

一、先分清三件事#

  • 外网带宽：运营商给多少兆，决定下载和看视频。
  • 内网质量：延迟、丢包、漫游切换，决定智能家居「听不听话」。
  • 覆盖密度：AP 数量与位置，决定有没有死角。

运营商升级到千兆只解决了第一项。全屋智能的痛点在第二、三项。

二、三种组网形态怎么选#

方案适用场景优点缺点
单台高性能路由60㎡ 以下、少隔墙便宜、简单边缘衰减大
Mesh（无线回程）已装修、无法布线免布线每跳约损失一半带宽，切换有卡顿
Mesh（有线回程）有网线、不想上企业设备稳定、易上手需提前布点
AC + AP（吸顶/面板）100㎡ 以上、智能家居设备多最稳、可调功率、支持 VLAN需布线、需配置能力
AC + AP + PoE新建/大平层/别墅一根网线搞定供电与数据交换机需支持 PoE

三、拓扑与关键设备#

  1. 光猫桥接：让路由器负责拨号，关闭光猫自带的 Wi-Fi，避免双层 NAT 与漫游混乱。
  2. 主路由/网关：负责拨号、DHCP、VLAN、访客网络。放弱电箱或机房。
  3. 交换机：按 AP 数量选口数，PoE 交换机可直接给吸顶 AP 与摄像头供电。留 30% 余量。
  4. AP：吸顶 AP 覆盖客厅/走廊，面板 AP 用于卧室（不占顶面）。同一品牌、同一系列，才能保证漫游协议一致。

四、IoT 一定要单独一个网段#

这是最容易被忽略、又最能提升稳定性的一步：

  • 智能家居设备（灯、插座、传感器）单独 SSID + 独立 VLAN，只开 2.4GHz。
  • 手机、电脑、电视走 5GHz 主网络。
  • 这样做的收益：减少广播风暴、避免设备被扫描、Wi-Fi 6 的 OFDMA 调度更干净。
  • 部分老设备只支持 2.4GHz，混在双频同名 SSID 下容易连不上，独立 SSID 也解决了这个问题。

五、验收标准（可执行）#

  • 每个房间用手机测速：信号强度 ≥ −65dBm，丢包 0。
  • 从客厅走到主卧边走边语音：切换延迟 <100ms，不中断。
  • 有线点位：测线仪 8 芯全通，协商速率 1Gbps/2.5Gbps。
  • 24 小时压力测试：连续 ping 网关，不出现超过 3 次丢包。

验收时不要只在客厅测速给客户看。全屋智能的体验发生在主卧、卫生间、阳台这些角落，那才是投诉来源。

六、常见死角与解法#

  • 卫生间：隔墙 + 瓷砖反射，建议走廊 AP 就近覆盖，或加面板 AP。
  • 主卧床头：面板 AP 常被床头柜挡住，抬高或改吸顶。
  • 开放式厨房：金属橱柜与油烟机形成遮挡，AP 避开油烟路径。
  • 阳台与入户：摄像头/门锁网关的信号需求，单独确认，必要时加小型 AP。

七、软路由、旁路由要不要上#

如果你只是想「网络稳定 + 智能家居好用」，成品主路由或 AC+AP 套装完全够用。软路由适合需要多拨、VLAN 精细策略、抓包排障的玩家，代价是维护成本和家庭网络「单点故障」风险。把复杂留给自己可以，但不要留给家人。

还有疑问？

Mesh 无线回程真的不行吗？

能用，但有前提：节点之间信号强度要好（实测 ≥ −60dBm），且数量不宜超过 3 个。每经过一次无线回程，吞吐大致减半，且切换会带来卡顿。如果家里已经布了网线，一定要走有线回程。

AP 越多越好吗？

不是。AP 过密会导致互相干扰与频繁切换。合理密度是每 2–3 个房间 1 个 AP，并把发射功率调到中低档，让设备自然选择最近节点。

1000M 宽带需要什么路由器？

2.5G 网口的主路由 + CAT6A 网线 + 支持 Wi-Fi 6/7 的 AP。注意瓶颈常在交换机与老网线上，而不是宽带本身。
